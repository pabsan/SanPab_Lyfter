Ejercicios de Joins
1. 
ORDER BY: 
Se utiliza para ordenar los resultados por una o varias columnas de manera ascendente o descendente.
Ejemplo:
ID  Nombre
2   Maria
1   Carlos
3   Ana

Select * from clientes order by ID desc
3  Ana
2  Maria
1  Carlos

LIMIT: 
Se utiliza para limitar el numero de filas (rows) en el resultado, sirve mucho en tablas con demasiada data entonces para no pegar la BD solo se obtiene una muestra de filas. Importante en SQL se utiliza top.
Ejemplo:
Select * from clientes limit 2
2 Ana
1 Carlos

GROUP BY: 
Se utiliza para agrupar el resultado en un conjunto de columnas, sirve para determinar duplicados o bien en conjunto para (y requisito) para sumar or contar elementos de una tabla.
Ejemplo:
select Nombre, Marca, sum(precio) as Total from Productos 
group by 
Nombre, Marca   Total
Laptop	Dell	 850
MacBook	Apple	 100000
Monitor	Samsung	 220
Mouse	Logitech 25.5
Teclado	HP	 45

INNER JOIN:
Combinas las filas de dos tablas basado en una o varias columnas que comparten una relación. Retorna las filas que coinciden el valor en todas las tablas unidas (inner).
Ejemplo:
Select f.NumeroFactura, s.Estado
From Facturas as f
inner join Estados as s
on f.IdEstado = s.Id

LEFT JOIN:
Combinas las filas de dos tablas basado en una o varias columnas que comparten una relación. Retorna todas las filas de la table izquierda más las filas que coinciden con la tabla derecha. Si no hay coincidencias en la tabla derecha se pone null en las columnas de la tabla derecha.
Ejemplo:
select c.NumeroContrato, j.TituloTrabajo
from contratos as c
left join trabajos as j
on c.jobid = j.id

Output
NumeroContrato TituloTrabajo
234		Mensajero
333		NULL
123		Programador


RIGHT JOIN:
Lo mismo que left pero viceversa... :)
Combinas las filas de dos tablas basado en una o varias columnas que comparten una relación. Retorna todas las filas de la tabla DERECHA más las filas que coinciden con la tabla izquierda. Si no hay coincidencias en la tabla izquierda se pone null en las columnas de la tabla derecha.
Ejemplo:
select c.NumeroContrato, j.TituloTrabajo
from contratos as c
right join trabajos as j
on c.jobid = j.id

Output
NumeroContrato TituloTrabajo
234		Mensajero
123		Programador
NULL		Enfermero
